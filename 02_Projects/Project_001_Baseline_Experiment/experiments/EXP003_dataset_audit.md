# EXP003 Dataset Audit


## 实验目标

验证自动化数据审计流程，
统计工业视觉数据基本信息。


## 实验假设

脚本能够自动扫描数据目录，
获取图片数量和尺寸信息。


## 测试数据

3张RGB图片。


## 我的预测

程序能够：

1. 找到所有图片

2. 输出图片数量

3. 输出尺寸信息


## 实际结果

输出：

Total images: 3


Image sizes:

400×400

1080×1080

700×700


## 分析

脚本成功完成基础数据扫描。

同时发现：

不同图片尺寸存在差异。

真实工业数据需要统一输入尺寸。


## 结论

Dataset Audit基础流程建立完成。

# EXP003 Dataset Audit


## 实验目标

建立工业视觉数据自动审计流程，
分析数据数量、尺寸、通道和类别分布。


## 实验假设

脚本能够自动扫描数据目录，
并生成数据统计报告。


## 实验内容

实现：

- 图片数量统计
- 尺寸统计
- 通道统计
- 类别统计
- 报告生成


## 我的预测

程序能够：

1. 扫描全部图片
2. 输出统计信息
3. 保存dataset_report.txt


## 实际结果

Total images:

3


Image sizes:

(700,700)

(400,400)

(1080,1080)


Channel:

RGB:3


Class:

defect:1

good:2


生成：

results/dataset_report.txt


## 分析

1. 图片尺寸存在差异，需要统一输入尺寸。

2. 当前数据均为RGB格式。

3. 类别存在数量差异，需要关注类别不平衡。


## 结论

完成基础工业视觉Dataset Audit流程。

建立了自动化数据检查能力。
