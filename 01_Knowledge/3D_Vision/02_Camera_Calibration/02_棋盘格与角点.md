# 棋盘格与角点


# 1. 为什么标定需要已知几何结构


## 问题

相机标定的目标是得到真实相机参数：

- fx
- fy
- cx
- cy
- 畸变参数


但是相机只能够观察到图像中的像素：

(u,v)


如果只有图像信息：

无法知道：

- 这个点在现实世界的位置
- 点与点之间真实距离


因此需要一个：

已知三维结构的参考物。


通过比较：

真实世界中的几何关系

和

图像中的像素投影关系


反推出相机成像模型。


---

## 核心思想


已知：

真实空间点

(X,Y,Z)


观察：

图像像素点

(u,v)


建立：

3D空间 → 2D图像

之间的对应关系。


利用大量对应关系：

估计相机参数。



---

# 2. 为什么使用棋盘格


棋盘格是相机标定中最常用的标定板。


原因：


## 2.1 几何结构已知


棋盘格由规则排列的黑白方格组成。


每个角点之间的距离固定。


例如：

如果每个方格边长：

25mm


那么相邻角点之间的真实距离：

25mm



---

## 2.2 特征明显


黑白交替产生明显的灰度变化。


角点位置容易检测。


相比普通物体：

棋盘格具有更稳定的视觉特征。


---

## 2.3 成本低


棋盘格：

- 制作简单
- 尺寸明确
- 易于获取


因此成为工业和科研中常用标定工具。



---

# 3. 什么是 Object Points


Object Points：

表示标定板在真实空间中的三维坐标。


也称：

世界坐标点。


在棋盘格标定中：

由于棋盘格通常是平面。


可以定义：

Z = 0


例如：

棋盘格尺寸：

25mm


可以建立：


```

(0,0,0)

(25,0,0)

(50,0,0)

(0,25,0)

(25,25,0)

...

```


这些点的位置：

提前已知。


它们就是：

Object Points。



---

# 4. 什么是 Image Points


Image Points：

表示这些三维点在图像中的像素位置。


例如：

真实空间中的角点：


```

(25,25,0)

```


经过相机拍摄后：

对应图片位置：


```

(u,v)

(320.5,240.8)

```


这个二维坐标就是：

Image Point。



Image Points来源：

通过图像处理算法检测棋盘格角点得到。



---

# 5. Object Points 和 Image Points 的对应关系


相机标定的核心：

就是建立：


```

Object Point

```
    ↕
```

Image Point

```


例如：


真实棋盘格：

```

P1 = (0,0,0)

P2 = (25,0,0)

P3 = (50,0,0)

```


图片中：

```

p1 = (120.5,80.2)

p2 = (150.3,81.1)

p3 = (180.8,82.4)

```


形成：


```

(0,0,0)
↓
(120.5,80.2)

(25,0,0)
↓
(150.3,81.1)

(50,0,0)
↓
(180.8,82.4)

```


通过大量这样的对应关系：

计算：

- 相机内参
- 畸变参数
- 相机姿态



---
# 6. 什么是棋盘格内部角点


OpenCV标定使用：

棋盘格内部角点。


不是：

- 方格中心
- 外边框角点


而是：

黑白方格交界形成的内部交叉点。


例如：

```

□ ■ □

■ □ ■

□ ■ □

```


中间的交叉位置：

就是角点。


原因：

角点同时具有：

- 水平方向变化
- 垂直方向变化


因此具有较强的定位特征。



---

# 7. 方格数量和内角点数量的区别


这是标定中的常见错误。


例如：

棋盘格：

横向10个方格

纵向7个方格


那么内部角点数量：


横向：

10 - 1 = 9


纵向：

7 - 1 = 6



因此：

```

方格数量：

10 × 7

内部角点：

9 × 6

```


OpenCV中的参数：

表示的是：

内部角点数量。


不是方格数量。



---

# 8. 为什么角点适合做标定


角点具有明显的二维变化。


普通边缘：

只有一个方向变化。


例如：

```

## ██████

```

沿边缘方向：

位置难以确定。


而角点：

```

□■
■□

```


同时具有：

水平变化

和

垂直变化。


因此可以更加精确定位。


在高精度标定中：

通常会进一步进行亚像素优化。


提高角点定位精度。



---

# 9. 为什么需要多个不同姿态


单张图片只能提供有限约束。


如果棋盘格：

一直保持：

- 同样角度
- 同样距离
- 同样位置


那么获得的信息重复。


导致部分参数难以准确估计。



因此需要：

不同姿态的图片。


例如：

- 不同距离
- 不同倾斜角度
- 不同旋转方向
- 覆盖图像中心和边缘


这样可以提供更多几何约束。



最终帮助算法更准确估计：

- fx
- fy
- cx
- cy
- 畸变参数

# 10. 我的理解

已知世界

↓

观察图像

↓

反推出相机模型。


棋盘格提供了一个：

几何结构已知的参考物。


Object Points告诉算法：

现实世界中的点在哪里。


Image Points告诉算法：

这些点在照片中的位置。


通过大量对应关系：

算法可以反推出：

相机到底如何观察世界。


如果没有这些已知几何约束，

相机只能看到二维图片，

无法准确恢复三维空间信息。
