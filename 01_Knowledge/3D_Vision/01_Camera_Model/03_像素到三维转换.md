# 像素到三维坐标转换（Pixel to 3D）


# 1. 为什么需要像素到三维转换


计算机视觉中，图像提供的信息是二维的。


例如：

图片中检测到一个目标：

```

u = 350

v = 260

```


这只能说明：

目标在图片中的位置。


但是机器人需要：

```

X = ?

Y = ?

Z = ?

```


也就是：

目标在真实空间中的位置。


因此需要完成：

二维像素坐标

↓

三维空间坐标


这个过程称为：

像素到三维坐标转换。



---

# 2. 转换需要哪些信息


一个二维像素点：

```

(u,v)

```


本身无法确定三维位置。


原因：

同一条视线上有无数个点。


例如：

```

相机

|
|
*
|
*
|
*

```

图片中同一个像素：

可能对应：

距离100mm的物体

也可能对应：

距离1000mm的物体。


因此需要额外信息：

## 深度 Depth


表示：

物体距离相机的距离。


记为：

```

Z

```


---

# 3. 转换所需参数


已知：


## 像素坐标


```

(u,v)

```


表示：

目标在图片中的位置。



---

## 深度


```

Z

```


表示：

目标距离相机多少距离。


单位：

mm

或者：

m



---

## 相机内参


包括：

```

fx

fy

cx

cy

```


描述：

相机如何成像。



---

# 4. 核心公式


像素坐标转换到相机坐标：


## X方向


```

X = (u-cx)*Z/fx

```


---

## Y方向


```

Y = (v-cy)*Z/fy

```


---

## Z方向


```

Z = Z

```



最终：

```

(u,v,Z)

↓

(X,Y,Z)

```



---

# 5. 公式推导理解


## 5.1 水平方向


观察：


```

图片中心

```
   |
   |
   *
   |
```

```


cx表示：

光轴中心。


因此：

```

u-cx

```


表示：

目标距离图像中心多少像素。


如果：

```

u > cx

```


目标在右侧。


如果：

```

u < cx

```


目标在左侧。



---

## 5.2 为什么需要除以fx


fx表示：

像素和真实空间的比例关系。


例如：

相同30个像素偏移：


近处：

可能只代表20mm。


远处：

可能代表50mm。


fx负责把：

像素距离

转换成：

空间距离。



---

# 6. 实例计算


假设：


## 图像坐标


```

u=350

v=260

```


## 深度


```

Z=500mm

```


## 相机参数


```

fx=600

fy=600

cx=320

cy=240

```



---

## 计算X


公式：


```

X=(u-cx)*Z/fx

```


代入：


```

X=(350-320)*500/600

```


得到：


```

X=25mm

```



含义：


目标在相机右侧25mm。



---

## 计算Y


公式：


```

Y=(v-cy)*Z/fy

```


代入：


```

Y=(260-240)*500/600

```


得到：


```

Y=16.7mm

```


含义：

目标在相机下方16.7mm。



---

## Z


```

Z=500mm

```


表示：

目标距离相机500mm。



---

# 7. 三维坐标结果


最终：


```

(X,Y,Z)

=

(25,

16.7,

500.

````


表示：


目标：

- 水平方向右侧25mm
- 垂直方向下方16.7mm
- 距离相机500mm

# 8. Python实现


代码：

```python
import numpy as np


def pixel_to_camera(u, v, depth,
                    fx, fy, cx, cy):

    X = (u - cx) * depth / fx

    Y = (v - cy) * depth / fy

    Z = depth

    return np.array([X,Y,Z])



if __name__ == "__main__":


    point = pixel_to_camera(
        350,
        260,
        500,
        600,
        600,
        320,
        240
    )


    print(point)

````

输出：

```
[25.0 16.67 500]
```

# 9. RGB-D中的实际应用

真实RGB-D相机：

例如：

Intel RealSense

输出：

RGB：

```
颜色图像
```

Depth：

```
每个像素距离
```

例如：

```
pixel(350,260)

depth=500mm
```

通过内参：

```
fx

fy

cx

cy
```

可以得到：

```
X,Y,Z
```

于是：

机器人知道：

物体在哪里。

# 10. 常见错误

## 错误1：没有深度信息

只有：

```
u,v
```

无法得到：

```
X,Y,Z
```

---

## 错误2：内参错误

如果：

```
fx,cx
```

错误。

计算出的三维位置会偏移。

---

## 错误3：坐标系混乱

需要区分：

像素坐标：

```
u,v
```

相机坐标：

```
X,Y,Z
```

世界坐标：

```
Xw,Yw,Zw
```

# 11. 我的理解

像素到三维转换，本质是：

给二维图像增加空间信息。

二维视觉回答：

“目标在哪里？”

三维视觉回答：

“目标距离我多远，在空间哪个位置？”

机器人只有获得：

(X,Y,Z)

才能进行：

* 抓取
* 避障
* 导航
* 操作

因此：

像素到三维转换是机器人视觉的基础。
