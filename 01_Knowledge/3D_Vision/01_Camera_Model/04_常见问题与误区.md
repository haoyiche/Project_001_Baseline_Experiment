# 相机模型常见问题与误区


# 1. 像素坐标不是空间坐标


## 错误理解

看到目标：

```

u=350
v=260

```

认为：

```

X=350
Y=260

```


这是错误的。


原因：

(u,v)只是图片上的位置。


单位：

pixel


而：

(X,Y,Z)

表示真实空间位置。


单位：

mm 或 m



---

# 2. 为什么只有(u,v)无法得到三维坐标


一个像素点：

```

(u,v)

```


对应的是一条射线。


例如：

```

```
    相机

      |
      |
      |
      *
      |
      |
      *
```

```


沿着同一方向：

可能存在无数个空间点。


因此必须增加：

深度信息 Z。



---

# 3. 深度Z不是普通坐标


## 常见误区


认为：

Z只是第三个坐标。


实际上：

在像素恢复过程中：

Z代表：

目标距离相机的距离。



例如：

```

Z=500mm

```


表示：

目标距离相机500mm。



---

# 4. fx和fy不是毫米单位


## 错误理解


认为：

```

fx=600mm

```


这是错误的。



实际：

fx单位：

pixel



表示：

焦距在图像坐标中的等效长度。



---

# 5. fx越大意味着什么


## 常见误区


认为：

fx越大：

相机看得越远。


不准确。


正确理解：


fx越大：

视场角越小。


物体在图片中占据更多像素。


类似：

长焦镜头。


---

# 6. cx和cy不是物体中心


## 错误理解


认为：

cx、cy表示：

目标的位置。


错误。


它们表示：

相机光轴在图像中的位置。



例如：

640×480图片：

理想情况：

```

cx=320

cy=240

```


表示：

图像中心。



---

# 7. 内参不是随便设置的


## 错误理解


代码中：

```

fx=600

fy=600

```


可以永久使用。



实际：

每个相机不同。


真实项目需要：

相机标定。



例如：

RealSense：

可能：

```

fx=615.2

fy=614.8

cx=320.5

cy=241.1

```


这些参数来自：

标定过程。



---

# 8. 忽略镜头畸变


理想模型：

认为：

直线仍然是直线。


真实镜头：

存在：

- 径向畸变
- 切向畸变



表现：

图片边缘出现弯曲。



影响：

高精度定位时：

必须校正。



---

# 9. 坐标系混乱


计算机视觉中常见：


## 像素坐标


```

(u,v)

```


原点：

左上角。



---

## 相机坐标


```

(X,Y,Z)

```


原点：

相机光心。


通常：

Z向前。



---

## 世界坐标


```

(Xw,Yw,Zw)

```


原点：

人为定义。


例如：

机器人基座。



---

错误：

直接把：

相机坐标

当成：

机器人坐标。


实际需要：

坐标转换。



---

# 10. 单位错误


常见问题：

深度单位：

毫米


但是程序：

认为：

米。



例如：

真实：

500mm


输入：

500


如果程序认为：

500m


结果会完全错误。



必须统一：

mm

或者：

m



---

# 11. 深度相机不是万能的


Depth存在误差：

来源：

- 反光物体
- 黑色物体
- 透明物体
- 距离过远
- 环境光影响



工业应用需要：

滤波和误差分析。



---

# 12. 检测准确不代表定位准确


例如：

YOLO检测：

非常准确。


但是：

三维定位仍可能错误。


原因：

定位依赖：

- 内参
- 深度
- 坐标转换
- 标定精度



视觉系统：

不仅需要识别，

还需要测量。



---

# 13. 工程调试顺序


出现三维定位错误时：

不要直接改模型。


应该检查：


## Step 1

确认检测框正确。


↓

## Step 2

确认深度数据正确。


↓

## Step 3

确认内参正确。


↓

## Step 4

确认坐标转换公式。


↓

## Step 5

确认单位。


↓

## Step 6

检查外参转换。



---

# 14. 我的理解


相机模型看似简单：

一个公式：

```

X=(u-cx)Z/fx

```


但是工程应用中：

真正困难的是：

保证每个参数都有正确的物理意义。


三维视觉不是：

把二维图片变成三维。


而是：

建立计算机和真实世界之间可靠的空间关系。
