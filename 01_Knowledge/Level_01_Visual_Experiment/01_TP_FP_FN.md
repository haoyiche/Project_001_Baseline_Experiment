# TP / FP / FN

## 1. 为什么需要它们

模型输出预测结果以后，
需要与真实标注 Ground Truth 比较。

根据预测与真实情况的关系，
可以将结果分类。


## 2. TP - True Positive

实际有目标，
模型也正确检测到目标。

工业缺陷检测：

实际：有裂纹
模型：检测出裂纹

=> TP


## 3. FP - False Positive

实际没有目标，
模型却认为存在目标。

工业缺陷检测：

实际：正常区域
模型：判断为裂纹

=> FP

中文通常称：

误检


## 4. FN - False Negative

实际存在目标，
模型却没有检测出来。

工业缺陷检测：

实际：存在裂纹
模型：没有发现

=> FN

中文通常称：

漏检


## 5. 工业意义

FP过多：
正常产品可能被错误剔除。

FN过多：
缺陷产品可能被错误放行。


## 6. 我的理解

TP就是 真正意义上的找到了真正错误
TN就是 正确的确实是正确的
FP就是 错误的当成正确的 也就是误判
FN就是 错误的没有找到，也就是漏检

为什么 FN 对某些工业检测任务特别危险？

因为如果漏掉了某些可能影响系统损坏的错误，那么对整个系统的危害是最大的，可能导致系统崩溃。

在高风险工业检测任务中，FN意味着真实缺陷没有被发现。如果缺陷进入后续生产流程，可能导致设备损坏、安全事故或产品质量问题，因此某些场景需要优先降低FN数量，提高Recall。
