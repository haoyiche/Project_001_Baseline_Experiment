# Dataset 与 Baseline


# 1. 为什么需要数据集设计


深度学习模型的效果不仅取决于模型结构，

还取决于：

- 数据质量
- 数据分布
- 标注质量
- 数据划分方式


模型学习的是：

输入数据中的规律。


如果训练数据不能代表真实场景，

模型上线后可能失效。



---

# 2. Dataset组成


视觉任务数据集通常包含：


Image

+

Annotation



其中：

Image：

输入图片。



Annotation：

人工标注信息。



目标检测任务中：

Annotation包括：

- 类别 Class
- Bounding Box



例如：

图片：

factory_001.jpg


标注：

class:

defect


bbox:

[x1,y1,x2,y2]



---

# 3. 为什么数据质量重要


机器学习中：

Garbage In, Garbage Out


含义：

错误的数据输入，

会导致错误模型输出。



例如工业缺陷检测：


训练数据：

- 固定光照
- 固定角度
- 固定背景



实际生产：

- 不同光照
- 不同设备
- 不同环境



模型可能失效。



---

# 4. 数据集划分


通常分为：


Dataset

├── Train

├── Validation

└── Test



---

# 5. Train Set


训练集。


作用：

让模型学习参数。



模型通过训练数据学习：

- 特征
- 模式
- 分类规律



例如：

学习：

裂纹有哪些纹理特征。



---

# 6. Validation Set


验证集。


作用：

模型开发阶段进行比较和调优。


用于：

- 模型选择
- 参数调整
- 数据增强选择
- 学习率调整



验证集不直接更新模型参数。



---

# 7. Test Set


测试集。


作用：

最终评价模型泛化能力。


测试集应该：

训练过程中不可使用。



原因：

如果测试数据参与模型调整，

评价结果会失真。



---

# 8. 数据泄漏（Data Leakage）


定义：

测试信息进入训练过程。


结果：

模型效果虚高。



---

## 例子1：图片泄漏


错误：


训练：

image001.jpg


测试：

image001_crop.jpg



虽然文件不同，

但是内容高度相似。


导致：

测试结果虚高。



---

## 例子2：时间泄漏


工业生产：

1月数据

2月数据

3月数据



错误：

随机划分。



正确：

按照时间划分。


训练：

1-2月


测试：

3月



更接近真实部署。



---

# 9. Baseline


Baseline：

基线模型。



定义：

一个简单、可靠、可复现的初始方案。



作用：

作为后续实验比较标准。



---

# 10. 为什么需要Baseline


没有Baseline：

模型A：

90%

模型B：

92%



无法判断：

提升来自：

- 模型结构？
- 数据？
- 参数？
- 随机因素？



有Baseline：


Baseline:

85%


改进方案：

90%



可以分析：

提升原因。



---

# 11. 公平实验原则


比较两个模型时：

需要控制变量。



保持：

- 数据集一致
- 数据划分一致
- 评价指标一致
- 输入尺寸一致
- 训练策略尽量一致



否则：

实验结果无法说明模型差异。



---

# 12. 实验设计思维


不要：

“试一个模型看看效果。”



应该：

提出假设。



例如：


问题：

小目标缺陷检测效果差。



假设：

输入分辨率不足导致细节丢失。



实验：

方案A：

640×640


方案B：

1280×1280



比较：

- mAP
- Recall
- 小目标指标



得到结论。



---

# 13. 我的理解


模型效果不是只由网络结构决定。


一个可靠实验需要：

正确的数据划分，

合理的Baseline，

公平的比较条件，

明确的问题假设。



算法工程师的价值不仅是训练模型，

更重要的是：

通过实验找到问题原因，

证明改进方法有效。
