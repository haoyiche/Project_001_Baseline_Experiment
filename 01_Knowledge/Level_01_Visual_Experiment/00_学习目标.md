# LEVEL 1 视觉实验与评测能力

## 学习目标

从“会训练视觉模型”升级为“会评估、分析和改进视觉模型”。

学完后能够：

- 正确选择视觉任务评测指标
- 理解 TP / FP / FN
- 理解 Precision / Recall / F1
- 理解 IoU / AP / mAP
- 分析模型失败原因
- 设计对照实验和消融实验
- 判断模型是否具备工程部署价值
- 使用数据而不是主观感觉得出结论

## 最终项目

Industrial Vision Benchmark Lab

## 通关标准

能独立完成视觉模型：

数据检查
→ Baseline
→ 评测
→ 失败分析
→ 对照实验
→ 消融
→ 工程指标
→ 技术结论
